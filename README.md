# Korrektur Wrapper

Lokale Software zur KI-gestützten Rechtschreibkorrektur literarischer Texte.

## Für wen

Für eine Autorin, die lange Bücher (ca. 400 Seiten) in Microsoft Word (`docx`) schreibt — oft per Diktierfunktion. Kapitel sind typischerweise 20–30 Seiten. Die Standard-Rechtschreibprüfung von Word und Google ist ungeeignet, weil literarischer Stil, Wortneuschöpfungen, Namen und Wörter anderer Sprachen fälschlich als Fehler markiert werden.

## Ziel

Ein Kapitel als Word-Datei öffnen. Die KI markiert *potenzielle* Fehler. Pro Fundstelle:

1. eine von drei kontextbezogenen Korrekturvorschlägen wählen,
2. ein eigenes Wort eingeben, oder
3. „Das ist kein Fehler“ markieren.

Danach die korrigierte Datei lokal speichern. Das Original wird nicht still überschrieben.

Die KI soll wie eine Lektorin mit literarischem Gespür vorschlagen — nicht wie der Duden.
